# ☁️ 云形成高阶仿真实验 · Cloud Formation Simulation

基于原生 HTML/CSS/JavaScript 开发的交互式物理仿真项目，还原云的形成原理，搭配B站风格高级可视化效果。

---

## ✨ 项目简介
本项目以**温度、水汽、凝结核**为核心变量，模拟大气中云的形成过程：
- 当环境温度高于0℃时，水蒸气无法液化，不能形成云；
- 当温度降至0℃以下时，水蒸气会附着在凝结核表面，不断凝结形成云团。
项目采用深色主题+磨砂玻璃UI+流体粒子效果，实现专业级可视化体验，可直接用于课堂展示、科普演示或个人学习。

---

## 🚀 核心功能亮点

### 1. 可调节物理参数
| 参数 | 调节范围 | 作用 |
|------|----------|------|
| 水蒸气密度 | 15 ~ 85 | 控制参与运动的水汽粒子数量 |
| 凝结核浓度 | 6 ~ 45 | 空气中的尘埃颗粒，是云形成的关键 |
| 环境温度 | -20℃ ~ 20℃ | 决定水汽能否液化成云 |
| 空气流速 | 12 ~ 100 | 控制粒子运动快慢，模拟风的影响 |

### 2. 流体云团特效
- 水汽粒子带脉动光晕，模拟真实水分子活跃度
- 低温下自动生成模糊流体云团，缓慢向上飘散
- 粒子边界回弹、碰撞逻辑自然流畅

### 3. 智能分析系统
根据温度和运行状态，自动切换解说文案，模拟AI分析：
- 高温状态：提示“水分子活跃度高，无法凝结”
- 临界温度：提示“难以形成有效云团”
- 低温状态：提示“持续凝结，云量不断增加”

### 4. 高级UI动效
- 深色渐变背景 + 磨砂玻璃分层设计
- 3D实验箱体带呼吸浮动动画
- 按钮、滑块带流光hover效果
- 实时数据面板，显示云团数量和运行状态

## 📦 使用方法
1. 下载本项目文件：
   - `index.html`：主程序文件
2. 双击 `index.html`，用Chrome/Edge浏览器打开即可运行
3. 操作说明：
   - 调节右侧参数滑块，实时改变实验条件
   - 点击「启动仿真」，粒子开始运动
   - 温度低于0℃时，画面会自动生成云团
   - 点击「重置系统」恢复初始状态
